Container

Any element with an opening and closing tag that holds content.

<div>

Generic block container with no meaning of its own. This tag is useless without a class or id attribute.

<span>

Generic inline container with no meaning of its own. This tag is useless without a class or id attribute.

Block vs. Inline

A block container (element) starts on a new line and stretches across its parent container's full width.
An inline container (element) stays in the flow of the line and takes only as much room as its content.

Semantic Elements

<article> Element - this contains content that can stand alone outside of the current web page.

<aside> Element - this contains content that relates to the current web page indirectly, and is not part
of the main content. An examle of an aside would be an advertising link on a website, which is often
created in a section off to the right side of a page. Like this manual that you've already seen before.
