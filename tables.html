The Table Element

<table> - This is the element that creates an HTML table. NOTE: HTML tables are used to organize data into rows and columns.

Cell

Cell - it is a location in the table at a specific row and column. Cells are created at the intersection of a row and a column.

Table Row

<tr> - an element that creates a row in a table. Table rows are NESTED inside table elements.

Table Header

<th> - the element that creates a cell containing table header information about the data contained in a specific column.
