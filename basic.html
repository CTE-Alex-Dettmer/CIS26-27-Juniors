HTML Lists

There are 3 types of HTML lists:

Unordered Lists

Unordered lists are lists that have bullet points to the left of each list item. These lists are contained in an <ul> tag.

  • Cedric
  • Ian
  • Alex
  • Levi
  • Martin
  • Angus
  • Kaleb

NOTE: Unordered Lists are the base HTML structure used to create navigation.

Ordered Lists

Ordered Lists are used to create a sequence of items or steps. These list items have a number, Roman numeral, or alphabetic character to the left of each item. Like <ul> items, ordered list items are contained in <li> tags.

  1. Step 1: crack eggs
  2. Step 2: add milk
  3. Step 3: whisk eggs and milk
  4. Step 4: pour into a hot pan
  5. Step 5: contemplate your poor life choices :D

Anchor Tags

Anchor elements define hyperlinks in a web page. A hyperlink, or link, specifies where other information is located and what action the web browser should perform when the user clicks the hyperlink.

The <a> tag by itself is useless without the href (Hyperlink-reference) attribute. If a hyperlink takes you away from your website, you should always open it in a new browser tab.

Official flight manual for the Lockheed Martin F-16C
E.T. go home!

Absolute & Relative URLs

URLs (Universal Resource Locators) are otherwise known as web addresses.

Absolute URLs are complete URLs including the transfer protocol. Example:
https://www.canton.edu/cyber/

HTTPS: HyperText Transfer Protocol Secure.

Relative URLs specify a "relative" path to the web resource with no scheme or host name. They refer to resources based on the current web address you are in.
Example:
<a href="index.html"></a>

Section Links

A URL can point to a section, or FRAGMENT, of a document by adding a hashtag (#) and a fragment identifier at the end of the URL.

Example:
https://en.wikipedia.org/wiki/Computer_science#History

The section listed after the hashtag refers to a class or ID attribute. EX:
<section id="History">
